# Dock case (draft)

3D model of the dock case for the Switch Lite, designed around the **X96Q Pro** TV box: the box sits inside the case, so other boxes will most likely not fit without changes. It was designed in AutoCAD; this folder holds a STEP export for editing and STL/3MF files for printing.

| File | What it is |
|---|---|
| `LiteDock_shell.stl` | Shell |
| `LiteDock_lid.stl` | Lid |
| `LiteDock_A1_plate.3mf` | Ready-to-print plate for the Bambu Lab A1 (both parts) |
| `LiteDock.step` | Editable CAD model (STEP, opens in Fusion, FreeCAD, SolidWorks and others) |

## Known issues

- **The bottom USB-C connector needs to be a long one.** With a regular USB-C plug the console does not click all the way into the port.
- **HDMI does not fit in the standard position.** With the box seated normally the HDMI cable cannot be plugged in, so the case has an opening on the side for it as a workaround.
- The original AutoCAD file (`.dwg`) is not published: it was made under a non-commercial license. Use the STEP export to edit the model.
